---

## 🎯 Features

### 📈 Marks Prediction
Estimate expected exam marks using study hours and study intensity.

### 📅 Study Schedule Management
Create, organize, prioritize, and complete daily study tasks.

### 📊 Progress Analytics
Visualize study consistency, task completion rates, and progress through interactive charts.

### 🎯 Daily Goal Tracking
Monitor completed tasks, study goals, and study streaks.

### 🤖 Personalized Recommendations
Receive study suggestions based on recorded study activity and progress.

### 📁 Report Export
Export study progress and analytics reports in CSV and PNG formats.

### 💾 Local Data Storage
Store tasks and study history using JSON-based local data storage.

### 🌙 Responsive Interface
Interactive dashboard interface built with Streamlit.
